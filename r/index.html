Real R runs through webR. The first run downloads its runtime. Base R and bundled packages work here; additional packages need compatible webR builds. Desktop interfaces and arbitrary system software are unavailable.
Each run starts with fresh script variables and plots. Drafts, CSV text and answers are saved on this device when storage is available. Download a .R file for a separate copy. Runs have a 30-second execution limit; Stop ends the R session, including a busy loop, and the next run starts a new one.
