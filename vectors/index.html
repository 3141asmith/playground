Two ways to explore

Move any input vector to change its length and direction while keeping the others fixed. Move R to work backwards from the combined vector.

Right and up are positive. Directions are measured anticlockwise from +x. A zero vector has no defined direction.

Values use arbitrary units. Choose a larger grid for longer vectors. Focus an endpoint and use arrow keys; hold Shift for larger steps.

Components add independently. Add all horizontal components to find Rₓ and all vertical components to find Rᵧ. The resultant’s magnitude is √(Rₓ² + Rᵧ²).

With n vectors, dragging R shares its change equally: each vector changes by ΔR/n. Many combinations can give the same resultant. All endpoints stay inside the selected grid. Add up to eight vectors; remove extras from their cards.
